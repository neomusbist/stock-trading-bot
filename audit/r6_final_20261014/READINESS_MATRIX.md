## 2. 세부 안전 매커니즘 설명

### (1) 시장 정적 유예와 개별 종목 신선도 분리 (Two-Tier Guard)
- **시장 레벨 (Market-Wide)**: 비유동성 시간대나 장중 소강상태에서 10초 이내의 일시적 틱 지연은 웹소켓 연결이 정상인 한 불필요하게 주문 권한을 박탈(Blinking)하지 않습니다.
- **종목 레벨 (Per-Symbol Tick Freshness)**: 시장 전체가 `order_ready=True`라 할지라도, 주문 직전 해당 종목의 마지막 틱이 **5.0초를 초과한 경우** `runner.py:584`에서 `TICK_STALE` 사유로 신규 진입 주문을 원천 거절합니다.
- **효과**: 불필요한 깜빡임은 제거하되, 급변동이나 호가 공백 상태의 종목에 체결되는 참사는 완벽히 방지합니다.

### (2) 계좌 상태 및 네트워크 Fail-Closed 원칙
- 웹소켓 단절이나 증권사 API 응답 지연 발생 시, 1초의 유예도 없이 즉시 `order_ready=False`로 전환되어 신규 매수가 원천 차단됩니다.
- 기존 보유 포지션에 대한 청산(손절/익절) 감시는 백그라운드에서 독자 안전 쓰레드로 유지됩니다.
