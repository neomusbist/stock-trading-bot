## 2026-10-20 후속: 전달 공정성과 내구성 저장

기준 `7ee7a2eb1d50c5aa9244d5857a5864ee02c788eb`의 기존 7개 수정 및 221개 검증을 보존하고, SHADOW 평가·WATCH 큐 인계와 계좌 대조의 중복 저장만 보완했다. 새 전략, 안전한도·신선도·전략 게이트 변경, LIVE 반영은 없다.

- 일반 WATCH 프레임만 대기하면 이미 인계가 끝난 SHADOW 틱을 제한된 예산 안에서 평가한다. 큐 뒤에 있는 제어·주문·보유 종목 프레임도 먼저 처리한다.
- 승격 큐를 잠금 안에서 분리하여 남은 FIFO를 재삽입하다 순서가 바뀌거나 가득 찬 큐에서 잃지 않는다. 승격 시 마지막 수용 틱을 기존 진입평가 경로에 한 번만 인계한다.
- main 큐 처리 도중 새로 도착한 관측은 평가 전에 다시 bounded prewarm으로 수용한다. detector가 모르는 최신 틱으로 오래된 입력을 교체하지 않는다. 중복 프레임·신선도 초과는 차단한다.
- 성공적인 계좌 대조에서 임시 중간 상태와 최종 상태를 이중 저장하던 경로를 한 번의 최종 durable checkpoint로 줄였다. core 단독 대조, 주문 의도·체결·오류의 동기 저장은 유지한다. 최종 저장 실패 시 account_ok=false로 닫는다.

이번 최초 새 회귀 10개는 기준에서 7 FAIL / 3 PASS, 수정 후 10 PASS다. 첫 평가가 새 포지션을 만든 직후의 보호 우선권과 이미 복사한 SHADOW 이력의 승격 틱 인계 반례를 추가했다. 최종 신규 12개는 기준에서 9 FAIL / 3 PASS, 수정 후 12 PASS다. 기존 221개와 관련 저장·복구·큐·주문 경로 검사를 포함한 최종 결과는 **285 PASS / 0 FAIL / 0 ERROR / 0 SKIP**, 네트워크 연결 시도·실주문 0이다. 무결성 보호를 유지한 OFFLINE_TEST_ONLY 사본에서 검증했고 수정 소스와 바이트 일치를 확인했다.

## 검증과 한계

표적 52개 검사를 통과했다. 별도 테스트 복제본의 전체 적용 범위 검사에서는 1,887개를 실행해 1,886 PASS, 1 FAIL, ERROR/SKIP 0을 기록했다. 유일한 실패는 AG가 LB 연구 trial을 추가했는데 기존 진단 시험은 전체 trial이 A/B/C 3개라고 가정한 문제이며, 인수 원형 8174b5d에서도 똑같이 재현했다. ABC 3개와 LB 1개를 분리하고 LB의 주문 부적격·기각 이유 및 SHADOW 경계를 추가로 검사하도록 고쳤다. 실패를 삭제하거나 주문 안전 기대값을 낮추지 않았다. 최종 파일 기준 해당 모듈과 표적 검사를 합친 62개가 PASS했다. 전체 검사를 두 번째로 모두 통과했다고 표현하지 않는다. 복제본의 manifest는 테스트 전용이고 배포 승인 근거가 아니다. 미배포 연구 시험 49개는 전체 검사에서도 제외되어 미실행이다.

코드 경로에서는 신호 이후 실제 주문 심사, 지연 체결, 부분 매수·매도, 취소, 중복 방지, 수동 보유 분리, 비상선 갭 손실, 확정봉 구조 훼손을 재현했다. 4%는 추가 진입을 막는 한도이며 갭 체결로 실현 손실이 초과할 수 있다. 미래의 가격으로 지난 MFE를 바꾸지 않는다.

캐시 단독 결과는 **거래 수·순손익 UNKNOWN**이다. 저장된 10/19·20 체결 저널과 WATCH 확정봉을 연결한 탐색에서도 동시점 메타데이터·연속된 봉이 부족한 구간이 많았다. 이 결과를 시장에 기회가 없었다거나 새 가설이 실패/성공했다는 증거로 사용하지 않는다. 기존 A/B/C/FAST 로그는 선택된 WATCH 표본이고 전체 기회 모집단이 아니다.
