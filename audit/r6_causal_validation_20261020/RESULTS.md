# 인과적 백테스트 교정 — 개발 전용, LIVE NO-GO

인수 기준은 `8174b5d790f36086488e84bb5d0733371fe07aaf`이다. 원래 AG 스크립트·자료는 해당 커밋과 원래 개발 브랜치에 보존했다. 이 변경은 운영 배포가 아니다.

## 교정한 중대 오류

- 기존 89건·12승·77패·순손익 -71,184.2원, 계좌 재생 5건의 -2,948.5원/-3,020.1원은 원형에서 재현됐으나 **전략 성능으로 무효**다. START 표시 봉의 최종 OHLC를 시작 시각에 사용하고, 종가를 ask로, 한 틱 아래를 bid로, 양쪽 잔량을 1,000주로 만들었다.
- 마지막 저장 종가에 강제 청산하고, 청산 후 가격까지 MFE/MAE에 넣었다. 계좌 재생은 봇 현금·수동 자산·위험 기준을 혼동했고, 실제 주문·예약·부분체결 상태기계를 거치지 않았다.
- 인수한 10/20 캐시는 **8,545봉/129종목**이다. `REFERENCE_UNKNOWN` 3,573봉, `REST_REFERENCE` 4,025봉, `ACTUAL_RECEIVED` 947봉이다. 개별 이용 가능 시각이 없어 캐시만으로 실전 신호/체결을 확정할 수 없다. 10/19의 1,017봉도 완전한 시장 수신 자료가 아니다.

## 실제 변경

1. `core/market_evidence.py`: 봉 시작·완료·실제 이용 가능 시각, 실제 수신/참고봉, 누락·연속성을 분리한다. 이용 가능 시각은 분봉 종료만으로 추정하지 않는다.
2. `research/causal_data.py`, `causal_replay.py`: 실측 체결/호가, 명시적 가정, UNKNOWN을 구분한다. 실행 중인 로그는 시작 시점의 바이트 경계로 제한하고 SHA256을 기록한다. 정규장과 AFTER를 섞지 않는다.
3. `research/causal_account.py`: 임시 디렉터리와 네트워크 없는 전용 브로커에서 실제 `AutonomousEngine.enter` → PRE_HTTP → `cumulative_fill` → 포지션 → 기존 청산 함수를 호출한다. BUY 한도, 부분체결, 잔량 중복 사용, 취소, 중복 주문, 비용, 수동 HARD_LOCK, 실제 엔진 위험예산을 적용한다. 현재 잔량의 가상 체결은 실제 과거 체결이 아니다.
4. `automation/local_breakout.py`: 실제 시점의 확정봉·신선한 측정 호가가 없으면 평가를 보류한다. 가까운 저항을 무시하지 않고 최종 비상선으로 위험을 계산한다. 자체 0.95 손익비만으로 준비 완료라 표시하지 않고 기존 R6 공통 비용/손익비 검사까지 적용한다.
5. `automation/shadow_observation.py`: 연구용 봉 이용 가능 시각만 별도로 보존한다. A/B/C 워밍업이나 FAST 틱 테이프로 재주입하지 않는다.
6. `research/retest_strategy.py`: 확정 돌파→완성된 눌림→재상승과 당시 이미 알려진 국소 저항을 사용하는 **미검증 PAPER 가설**이다. 임의의 거래량 배수나 추가 지표는 넣지 않았다. 기존 구조적 손절·비상선·AE3 청산 경로를 사용한다.
7. AG의 여섯 재생/집계 진입점은 명시적 CLI로 교정했다. import가 계산·쓰기·모의 매매를 실행하지 않는다. 샘플 저널로 만든 봉은 `SAMPLED_JOURNAL_REFERENCE`이며 실제 수신 워밍업으로 쓰지 않는다.
8. `research/evidence_collector.py`: 기존 로그를 읽는 독립 수집기다. 구독·토큰·REST·LIVE 함수 호출 없이 최초 도착 순서의 미매수 형상 두 개까지 전후 증거를 저장한다. 반복 이벤트와 독립 에피소드를 구분하고 용량 제외/입력 공백을 기록한다.

## 검증과 한계

표적 52개 검사를 통과했다. 별도 테스트 복제본의 전체 적용 범위 검사에서는 1,887개를 실행해 1,886 PASS, 1 FAIL, ERROR/SKIP 0을 기록했다. 유일한 실패는 AG가 LB 연구 trial을 추가했는데 기존 진단 시험은 전체 trial이 A/B/C 3개라고 가정한 문제이며, 인수 원형 8174b5d에서도 똑같이 재현했다. ABC 3개와 LB 1개를 분리하고 LB의 주문 부적격·기각 이유 및 SHADOW 경계를 추가로 검사하도록 고쳤다. 실패를 삭제하거나 주문 안전 기대값을 낮추지 않았다. 최종 파일 기준 해당 모듈과 표적 검사를 합친 62개가 PASS했다. 전체 검사를 두 번째로 모두 통과했다고 표현하지 않는다. 복제본의 manifest는 테스트 전용이고 배포 승인 근거가 아니다. 미배포 연구 시험 49개는 전체 검사에서도 제외되어 미실행이다.

코드 경로에서는 신호 이후 실제 주문 심사, 지연 체결, 부분 매수·매도, 취소, 중복 방지, 수동 보유 분리, 비상선 갭 손실, 확정봉 구조 훼손을 재현했다. 4%는 추가 진입을 막는 한도이며 갭 체결로 실현 손실이 초과할 수 있다. 미래의 가격으로 지난 MFE를 바꾸지 않는다.

캐시 단독 결과는 **거래 수·순손익 UNKNOWN**이다. 저장된 10/19·20 체결 저널과 WATCH 확정봉을 연결한 탐색에서도 동시점 메타데이터·연속된 봉이 부족한 구간이 많았다. 이 결과를 시장에 기회가 없었다거나 새 가설이 실패/성공했다는 증거로 사용하지 않는다. 기존 A/B/C/FAST 로그는 선택된 WATCH 표본이고 전체 기회 모집단이 아니다.

새 정책의 거래 횟수, 순손익, 기대값, PF, MFE/MAE 및 지연·불리한 1틱 영향은 **독립 날짜의 충분한 실행 가능 표본이 없어 아직 판정 불가**다. 합성 주문 통과나 정상 눌림 보유 사례는 수익성 증명이 아니다.
